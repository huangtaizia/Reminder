# Reminder

Ứng dụng nhắc nhở cho Windows, xây dựng bằng Electron + React + Vite.

## Tóm tắt

- Chạy dưới khay hệ thống
- Nhắc giờ cố định và lặp lại
- Có thể khởi động cùng Windows và ẩn khi đóng
- Giao diện React + TypeScript

## Chạy nhanh

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
